**This folder contains the server of the MLOPS project**

# SERVER SPECIFICATIONS

---> Fastapi    : For creating (REST) API endpoints to expose the ML-MODEL over the internet.
---> Pydantic   : For input validation and base model creation.
---> pinacol    : For model importing and binary file creation.
---> postgresql : For the storing relational data.
---> pg-client  : For querying the database.
